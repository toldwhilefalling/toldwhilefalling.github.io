Privacy Policy

Last updated: November 11, 2026

This policy describes how the Told While Falling Uploader (“the app”) handles data. The app is a private tool operated by the owner of the Told While Falling channel and is used only to manage that channel.

What the app accesses

With the owner's permission, granted through Google sign-in, the app uses the YouTube Data API to upload videos to the owner's own YouTube channel, set their title, description, tags and publishing time, and read basic channel information (the channel name) to confirm which channel is connected.

What is stored

The app stores one OAuth refresh token on the owner's own computer so it can upload without signing in every time. It also keeps a local log of uploaded video IDs and publishing times. No data is stored on any server operated by the app.

What is not collected

The app does not collect, store or process data about viewers or any other YouTube users. It does not use analytics, cookies, advertising or tracking, and it does not sell or share any data with third parties.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access makes the stored token invalid; the owner can also delete it from their computer.

Changes

If this policy changes, the updated version will be published on this page with a new date.
